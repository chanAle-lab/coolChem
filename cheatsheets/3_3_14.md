# Topic 3.3.14 · Organic Synthesis (A-Level)

**Specification Coverage:** Designing multi-step synthetic routes (up to 4 steps), atom economy, avoiding hazardous solvents

## Synthetic Strategy & Green Chemistry

- **Multi-step strategy:** Work backwards (retrosynthesis) identifying required functional group interconversions (FGIs).
- **Key synthetic interconversions:**
- • Alkene -> Haloalkane (HX) -> Nitrile (KCN) -> Primary amine (LiAlH_4) or Carboxylic acid (acid hydrolysis).
- • Alcohol -> Aldehyde / Ketone -> Hydroxynitrile.
- • Benzene -> Nitrobenzene -> Phenylamine -> N-phenylethanamide.
- **Green chemistry goals:** Maximize atom economy, minimize number of reaction steps, avoid toxic solvents and reagents, use renewable feedstocks.
