# Topic 3.3.15 · NMR Spectroscopy (A-Level)

**Specification Coverage:** 13C NMR, 1H NMR, chemical shift, integration, splitting patterns (n+1 rule), TMS standard, solvents

## Principles & Reference Standard

- **Tetramethylsilane (TMS):** Standard reference assigned delta = 0 ppm. Inert, volatile (easily removed), produces a single sharp intense peak with 12 equivalent protons, non-toxic.
- **Solvents:** Must not contain protons (1H). Commonly **CDCl_3** (deuterated chloroform) or CCl_4.
- **13C NMR:** Number of peaks = number of distinct carbon environments. Chemical shift (delta) indicates environment type (carbonyl C=O at 160&ndash;220 ppm).

## 1H NMR Interpretation & Splitting (n+1 Rule)

- 1. **Number of peaks:** Number of non-equivalent proton environments.
- 2. **Chemical shift (delta):** Type of environment (alkyl 0.5&ndash;2, -O-CH_3 3.5&ndash;4, aromatic 7&ndash;8, aldehyde 9&ndash;10, carboxylic acid 10&ndash;12 ppm).
- 3. **Integration trace:** Ratio of protons in each environment.
- 4. **Spin-spin splitting (n+1 rule):** Peak splits into n+1 sub-peaks, where n is the number of non-equivalent protons on ADJACENT carbons:
- • Singlet (0 neighbours), Doublet (1 neighbour), Triplet (2 neighbours), Quartet (3 neighbours).
- • Protons on -OH and -NH typically do not split adjacent protons and appear as singlets.
